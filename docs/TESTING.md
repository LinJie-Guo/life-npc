# 测试与验证

本次 MySQL 集成验证于 2026-09-12 在本机 MySQL 8.4.5 上完成，42 项通过。完整结果见 [latest-mysql-results.json](../tests/latest-mysql-results.json)，测试实现见 [mysql.integration.ts](../tests/mysql.integration.ts)。

## 运行

先按 [部署说明](DEPLOYMENT.md) 配置独立测试数据库、应用环境并运行迁移和 API，然后执行：

```sh
npm run test:mysql
npm run lint
npx tsc --noEmit
npm run build:app
```

集成测试会注册测试账号、发布任务、上传测试附件并直接调整测试任务时间来验证截止行为，因此只能连接专用测试数据库。不要针对生产数据运行。测试账号使用运行时生成的凭据。

## 已覆盖的关键行为

- 注册、重复账号、密码哈希、会话、改密找回、恢复码轮换、退出与跨来源拒绝。
- 私有草稿、发布者权限、禁止自我报名获奖、多人独立参与、退出后重新报名。
- 并发争抢最后一个名额、重复报名、并发重复验收只发一次奖励。
- 草稿记录和附件隐私、MySQL 附件存储、提交、退回、修改后重新提交、验收。
- 截止后禁止报名和提交、过期状态、截止前提交在截止后继续验收、最终归档。
- 待验收时禁止取消、取消保留既有成就、停止招募保留参与资格。
- 保留的个人探索、收藏、活动、双人匹配、共同截止时间和取消流程。
- 高德未配置时明确提示。
